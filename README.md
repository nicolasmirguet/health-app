# Force Frère

Accompagnement chimio BEP — un compagnon de poche pour traverser 4 cycles × 21 jours.

## Démarrer

```bash
npm install
npm run dev      # serveur local
npm run build    # build production dans dist/
npm run preview  # preview du build
```

Vite + React 18. Aucune dépendance d'auth, aucune télémétrie. État persisté en `localStorage`.

## Avertissement médical

Cette application ne remplace pas l'avis d'un oncologue. En cas de doute, contacte ton équipe soignante.
